# Help & Support

**Route** `/help` · **Access** any signed-in user · **Source** [Help.jsx](../../frontend/src/pages/Help.jsx)

## What it does
A static page of answers to common questions. Nothing is loaded from the server.

## Sections
- **Getting started:** creating a task, changing password, position / department, switching theme.
- **Projects and team:** who can create projects and tasks, adding people, creating accounts, changing a project role.
- **Work, approvals and reminders:** how approval works, when deadline reminders arrive, where the schedule is.
- **Troubleshooting:** no access, not found, server unreachable, signed out or sign-in refused.
- **Still stuck?** Points to the workspace administrator.

## Notes
- The text is a list in the source file (`SECTIONS`); to change an answer, edit that list. Keep it in step with the app, because it is not generated from the code.
- The [Error page](error-page.md) links here.
