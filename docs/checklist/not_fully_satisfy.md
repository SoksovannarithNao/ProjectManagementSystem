These are bugs or weaknesses rather than missing features.

| R-3 | ~~Database grants must still be added by hand for each new table (this caused a 500 on `GET /api/tasks` for `work_logs`), in two lists that had to be kept in step~~ — **fixed 2026-10-14:** CI now runs `03-app-role.sh` itself (one list, no copy) and then `database/verify_grants.sql`, which fails the build for any table the app role cannot read unless it is one of the three that deliberately have no entity.
